# UNKNOWN DM

A mobile-first interactive mystery chat game.

## Play locally
Open `index.html` in a browser, or serve this folder with any static web server.

## GitHub Pages
The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml` that deploys the static game to GitHub Pages on pushes to `main`.

If Pages has not been enabled yet, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. Then run the **Deploy UNKNOWN DM to GitHub Pages** workflow from the Actions tab.

## Current build
- Interactive branching mystery chat
- Three collectible evidence clues
- Trust score and saved progress using local storage
- Mobile-first dark purple interface
- Installable web app manifest and offline service worker

This is a fictional story game. All characters and messages are invented.
